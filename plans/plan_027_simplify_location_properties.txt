#1 [done] Location properties are not modifiers
- [done] a building function output either has an amount or a reference to a location property
    - if it has an amount, that amount is applied to the building, wherever the building is placed on the map
    - if it has a reference to a location property, the value of that property on the building's location in the map is applied as the output amount
    - in building specification, this is specified as "<outputResourceType> <locationPropertyName>"
    - example:
            WorkTechnical 1
            =
            EnergyElectric insolation
        - this function produces EnergyElectric, in the amount of insolation on the location where the building is placed
        - a similar building which does not depend on insolation would have it's function definition:
            WorkTechnical 1
            =
            EnergyElectric 4
