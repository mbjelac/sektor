This describes extensions to the rendering code, applied in Architect & Frontend modules.

#1 [done] Pyramids can be hollow
- [done] when the h function is specified for a pyramid
    - pyramid is rendered as hollow from it's base
    - it is as if there is a "negative" pyramid inside, smaller, sharing the same base
    - h(0) means the pyramid is not hollow
    - h(100) means the pyramid is "paper thin", the "inside" pyramid is almost as same size, a tiny bit smaller
- [done] create visual tests for this

#2 [done] Cones can be hollow
- [done] apply equivalent of #1 to cones when h function specified
- [done] create visual tests for this

#3 [done] A pyramid can be frustum
- [done] when the "frustum" function is specified for a pyramid
    - f(<value>)
    - the pyramid is "cut"
        - by a plane horizontal to it's base
        - at a point on it's height specified by the f function value
            - 0: cut at the tip (no frustum visible)
            - 100: cut at base (almost height 0, a circle should remain)
    - both h & f functions can be specified on the same object, they have to work
- [done] create visual tests for this

#4 [done] A cone can be frustum
- [done] apply equivalent of #3 to cones when f function specified
    - both h & f functions can be specified on the same object, they have to work
- [done] create visual tests for this

#5 [done] A cylinder can be frustum
- [done] apply equivalent of #3 to cylinders when f function specified
    - a frustum cylinder means it is cut away with a plane parallel to it's axis
        - however rotated it is, it is always cut away on this plane
    - both h & f functions can be specified on the same object, they have to work
- [done] create visual tests for this

#6 [done] A sphere can be frustum
- [done] apply equivalent of #3 to spheres when f function specified
- [done] create visual tests for this

#7 [done] A sphere can be hollow
- [done] apply the hollow function to spheres
    - analogous to other bodies
    - value 100 means it is a paper-thin sphere
    - value 0 means it is full, like now
- [done] combination of functions h & f must work
