Building function specifies input & output amounts at 100% capacity.
Each building function's capacity can be changed by the player.
It can be changed fro 0 to 1 in steps of 0.1.
Initial capacity of a new building is 0.1.
If capacity is reduced to 0, the building is practically turned off: No inputs (imports) and no outputs (exports).
