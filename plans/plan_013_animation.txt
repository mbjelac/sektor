Both architect & frontend use shared code for rendering buildings as 3d objects.
This plan defines how to specify animations for those objects.
Both architect & frontend should apply those animations, if specified, in their rendering.

Improtant technical rule: All animations will be applied in animation steps.
All steps will be performed in a fixed rate with X milliseconds between them.
All animation steps will have to calculate amounts
so that they correctly achieve their specified parameters in the specified time.
For example, if a translation was specified as 50 units to happen during 200ms, and
steps are 20ms apart, each step should apply a change of 5 units,
because in a timespan of 200ms there will be 10 steps.

#1 [done] Objects move around
- [done] when translation animation specified, modify translation (t) parameters to the specified end during the specified time
    - specification for translation animation is at(dx, dy, dz, dt)
        - dx: how much to change x, 1st parameter of t function
        - dy: how much to change y, 2nd parameter of t function
        - dz: how much to change z, 3rd parameter of t function
        - dt: in what time period will the change happen
- [done] each translation animation has forward and backward phases
    - during the forward phase, t parameters are modified to the at specs during the specified time
    - afterwards animation enters backward phase in which t parameters are modified in reverse during the specified time
        - example:
            - at(0,0,30,100) first modifies height (z) from its specified value to +30 during 100ms
            - then in the backwards phase returns to -30 back to its initial state during the next 100ms
    - after backwards phase, another forward phase starts, etc.

#2 Color toggle
- when color toggle animation specified, object change their color for the specified duration, then change back to original color for the other specified duration
    - color toggle specification is act(c, dt1, dt2, dt3)
        - c: new color (also hex string prepended with #)
        - dt1: time during which original color is applied to object
        - dt2: time during which new color is applied to object
        - dt3: time during which original color is applied to object
    - dt3 is optional; if not present, it is assumed to be 0
