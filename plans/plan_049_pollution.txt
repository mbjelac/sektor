Some buildings emit pollution.
This is not part of imports & exports but it does have an area of effect.
If other buildings are constructed within that area they are affected.

Pollution reduces a location's natural level of soil & groundwater, affecting buildings which use that for production.
It also affects other buildings which are nture or people oriented:

Table of buildings and which pollution(s) they are affected by and in what way:
| Building    | Effect                                          |
|-------------|-------------------------------------------------|
| Park        | decreased all HealthX outputs                   |
| TownSquare  | decreased output HealthSocial                   |
| Forest      | decreased all outputs                           |

Table of polluting buildings:

| Building      | Area |
|---------------|------|
| Extractor     | 2    |
| Refinery      | 3    |
| Fertilizatron | 1    |

If two areas overlap, each adds it's pollution level to area squares.

#2 [done] Constructing a polluting building pollutes the area around it
- [done] when building spec contains property pollutionArea, building is a polluting building and constructing it increases surrounding pollution location property
    - buildings.md Properties section contains property pollutionArea=X
    - X is a number between 1 & 4
    - area polluted is a manhattan distance of x from the building
        - example for area 3:
               .
              ...
             .....
            ...x...
             .....
              ...
               .
    - the map's squares within the area have their location property "pollution" increased relative to the distance of the building
        - outer edge of the area is the lowest pollution
        - value increasng as distance to polluting building decreases
        - example for pollutionArea=3:
               1
              121
             12321
            123x321
             12321
              121
               1
        - the values 1-4 are actually percentages
            - 1 = 20%
            - 2 = 40%
            - 3 = 60%
            - 4 = 80%
    - pollution location property can have value between 0 & 100
        - representing the percentage of how much a location is polluted
    - when a polluting building (a building with pollutionArea > 0) is constructed, the pollution properties of neighbouring squares are increased by that percentage amount
        - it never increases beyond 100
    - when a sektor is loaded with polluting buldings already in it, pollution properties are already set to modified levels
    - when a polluting building is destroyed, the pollution properties are decreased by appropriate amount
    - when displaying pollution in building panel geography, use " %" suffix
- [done] when pollution is selected as overlay in main geography panel, color overlay based on pollution percentage
    - 0% black
    - 100% full pollution color
    - between 0% & 100% interpolate

#4 [done] Pollution affects location properties
- [done] location properties of a location with a non-zero pollution property are affected
    - affected properties:
        - soil
        - groundwater
    - affected location properties are first decreased by their inverse percentage of pollution
        - affectedProperty = round(originalProperty * (100 - pollutionProperty) / 100)
    - example:
        - soil = 8
        - polution = 80
        - when using value of soil in calculations (like for output of a building) the value 2 is used because of round(8 * 0.2)
- [done] affected location properties are indicated
    - in building panel geography section the affected properties are indicated to be affected:
        - their value is displayed as: "currentValue / originalValue ⚠️"

    - have warning in their building panel
        - beneath input & output table
        - text: "⚠️ Output decreased due to pollution!"
