Buildings can be connected by cycle roads.
A cycle road is a building (of sorts):
- it has inputs & outputs
- it has SGL rendering code
But also not a building:
- it is not rendered in a square, it is rendered *between squares*

The purpose of the cycle road is to allow some types of resources to be transported between buildings in the same sektor.

Type of resources transported by cycle roads is noted in resource list by having the "people" indicator.

#1 [done] Player can build cycle roads
- [done] every map edge can contain a cycle road
    - this means all roads are between two locations
    - if a road is on the edge of the map, one of the locations is outside the map, having it's x or y either -1 or 10 (map size)
    - roads can be stored into a structure which is a list of location pairs
- [done] roads are buildings on map edges
    - when player selects CycleRoad building in building toolbar
        - clicking on a square does not build that building
            - display error "roadsGoBetweenBuildings"
        - clicking on or near a map square edge
            - 5% tolerance
            - determine the two locations which pinpoint the location of the road
            - if the first location is in the map
                - render the road using this location
                    - determine side of location on which the road is (north, east, west, south)
                    - render using one of frontend/src/assets/terrain/temperate/cycle-roads according to that side
            - if the first location is not in the map, use the second location

#2 Player can destroy cycle roads
- when player selects Destroy
    - clicking on an empty edge
        - display error "locationEmpty"
    - clicking on a road
        - delete road from sektor
        - do not render that road

#3 Roads cannot be built on sea
- if both locations are sea
    - do not build road
    - show error "notDryEnough"

#4 Roads cannot be built over rivers
- if both locations are river
    - do not build road
    - show error "notDryEnough"
