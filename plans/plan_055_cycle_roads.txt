Buildings can be connected by cycle roads.
A cycle road is a building (of sorts):
- it has inputs & outputs
- it has SGL rendering code
But also not a building:
- it is not rendered in a square, it is rendered *between squares*

The purpose of the cycle road is to allow some types of resources to be transported between buildings in the same sektor.

Type of resources transported by cycle roads is noted in resource list by having the "people" indicator.

#1 Player can build cycle roads
- every map edge can contain a cycle road
    - this means all roads are between two locations
    - if a road is on the edge of the map, one of the locations is outside the map, having it's x or y either -1 or 10 (map size)
    - roads can be stored into a structure which is a list of location pairs
