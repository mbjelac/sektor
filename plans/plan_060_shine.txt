Bodies can shine: they glow with their own color, so that faces turned away from the light stay bright,
and glare where the light catches them.
Both architect & frontend use the shared rendering code, so both show shine and its animation.

#1 [done] Objects can shine
- [done] when shine specified, the body glows with its own color and glares where the light catches it
    - shine specification is sh(v)
        - v: shine strength, 0-100
            - 0 is no shine; it is the default when sh is not present
            - 100 adds 60% of the body's own color as glow on top of the light falling on it
                - c(#ffffff) sh(100) is pure white
        - the glare is a specular highlight whose strength follows v

#2 [done] Shine can be animated
- [done] when shine animation specified, the body's shine changes gradually from the original shine to the specified strength and back
    - original shine: the shine specified with sh, 0 if sh is not specified
        - v may be below the original shine, so ash can dim the shine too
    - shine animation specification is ash(v, duration, pause[, delay[, cycle pause]])
        - v: shine strength to arrive to, 0-100
        - duration: time in milliseconds during which shine changes from the original shine to v
        - pause: time in milliseconds during which shine stays unchanged at each end
        - delay: optional initial delay in milliseconds before the animation starts, 0 if absent
            - shine stays at the original shine during the delay
        - cycle pause: optional additional time in milliseconds during which shine stays at the original shine at the end of every cycle, 0 if absent
    - initial delay, then phases, repeating endlessly:
        - shine changes from the original shine to v during duration
        - shine stays at v during pause
        - shine changes from v back to the original shine during duration
        - shine stays at the original shine during pause
        - shine stays at the original shine during cycle pause
    - animation is applied in animation steps, like the other animations (plan 13)
