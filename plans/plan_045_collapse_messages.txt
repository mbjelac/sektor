#1 Player can remove messages in order to see the map
- if there is more than one message
    - top-most message has a collapse button on it
        - right aligned
        - icon heroicon chevron-down
        - white text
        - dark gray background
    - when clicked, collapse messages
- when messages collapsed, they are not shown

#2 Player can see the last message
- when messages collapsed, show only the top-most (last) message
    - hide collapse button
    - if message changes, still flash it like before

#3 Player can bring up messages again
- when messages collapsed, the single message has an expand button on it
    - right aligned
    - icon heroicon chevron-up
    - white text
    - dark gray background
    - when clicked
        - hide button
        - show all messages
        - show collapse button on top-most message
    - do not display expand button if there is only one message

#4 Player can see number of collapsed messages
- on expand button, next to icon, show number of collapsed messages
    - total number of messages minus one (the last one is always shown)
    - text is white, bold, small
