A system in which every building has to be connected to another building is:
- complicated
- hard to reason about (a lot of visual data)
- does not reflect reality of cities

In reality, multiple buildings get their needed resources from a *grid* transporting those resources around.
For now, we can ignore grids and just have a system where all resources are globally available to all buildings in a specific Sektor.
This greatly simplifies the Sektor architecture:
- each building's needed inputs & outputs are added to imports & exports
- an import & export for each resource is subtracted from each other so that one is zero and the other is positive, or they are both zero
    - example: two buildings have input water 5, a third building output water 7; resulting water import is 3 and export is 0
